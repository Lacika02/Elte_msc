In this project I had to recreate a study from these papers: https://analyticalsciencejournals.onlinelibrary.wiley.com/doi/10.1002/cem.3542 , https://link.springer.com/article/10.1007/s00292-025-01502-1.
Due to the sensitive nature of the ongoing project, I can not share code, only the last modified report I gave( heatmap prediction removed).  
With MIR spectra on colorectal tissue samples I researched the inner structure of the tissues. First using K-means I differentiated between the actual sample and the background,
then using XGBoost Dmatrix  with data streaming I trained a model. Result plots can be seen in the report.
