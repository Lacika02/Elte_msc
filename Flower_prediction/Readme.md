
## Flower Prediction Project

This folder contains the Jupyter Notebook used throughout the project, along with an HTML export from one of my final runs.

The first stage of the project involved reading and understanding the research papers in order to reproduce the published study. After that I acquired the  datasets and organized them using Pandas DataFrames for preprocessing and analysis.

The remainder of the project focused on data cleaning, exploratory data analysis, model implementation, training, evaluation, and comparing the results with those reported in the original study.
