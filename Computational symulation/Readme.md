# Lotka–Volterra Population Dynamics

This project is a C++ implementation of the generalized Lotka–Volterra model for simulating interactions between three species. The system is solved numerically using the Euler method, with configurable initial populations, growth rates, and interaction coefficients.

The accompanying report explains the mathematical background and documents the experiments I carried out, including reproducing a reference simulation, testing parameter sensitivity, species extinction, stable populations, and different types of species interactions.
